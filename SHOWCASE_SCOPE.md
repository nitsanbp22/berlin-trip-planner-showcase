# Showcase Scope

This repository is a curated portfolio case study for a private live Berlin travel-planning product.

Its purpose is to explain the product, UX, mapping and integration decisions without publishing the operational application or personal trip data.

## Included

- product case study documentation
- architecture and integration rationale
- collaboration and privacy model
- selected map and Google Places code samples
- approved screenshots when added

## Intentionally excluded

- production environment files
- Supabase project credentials
- Google API credentials
- private authenticated user data
- personal notes
- personal packing lists
- private tasks
- production exports
- complete trip database contents
- deployment-only configuration
- complete production source tree
- original Git history

## Production separation

The live private planner remains in a separate repository.

Changes made in this showcase do not modify or deploy the production application.

## Code samples

Code samples are curated from product-relevant implementation areas.

They are included for portfolio discussion and are not intended to form a complete deployable application.

## Visual assets

Only screenshots intentionally selected for portfolio use should be added to `assets/screenshots/`.

Before publication, screenshots should be checked for:

- personal email addresses
- private notes
- packing details
- account information
- sensitive trip details that do not add portfolio value
